# 記事ページ自動生成のしくみ（時の法）

スプレッドシートに記事を書くと、自動で次の3つが作られて公開されます。

- **記事ごとのページ** `articles/○○.html`（Google検索に1記事ずつ載るページ）
- **トップページの見出し一覧** `index.html`（全記事をHTMLに直接書き込み）
- **サイトマップ** `sitemap.xml`（Googleに全記事のURLを知らせる）

---

## 1. 最初に1回だけやること

### ① ファイルをリポジトリに入れる
このフォルダの中身を、GitHub の `tokinoho` リポジトリにそのままアップロード（上書き）します。
`.github` フォルダは見えにくいので、入っているか確認してください。

### ② スプレッドシートに E列「URL名」を追加
| A 日付 | B 見出し | C 本文 | D 出典URL | E URL名 |
|---|---|---|---|---|
| 2026-10-07 | 窃盗罪とは（刑法235条） | 【どういう法律か】… | | settou |

- **URL名** は記事ページのアドレスになります → `…/articles/settou.html`
- 半角の英小文字・数字・ハイフンだけ（例：`settou`、`meiyokison`、`2026-shogai`）
- **一度決めたら変えないでください。** 変えるとアドレスが変わり、検索での評価がリセットされます
- 空欄でも動きます（その場合は `2026-10-07-a1b2c3` のような名前になりますが、見出しを直すと名前も変わります）

### ③ スプレッドシートの公開URLを登録
1. スプレッドシートで「ファイル」→「共有」→「ウェブに公開」→ シートを選び、形式を **カンマ区切り形式（.csv）** にして公開
2. 表示されたURLをコピー
3. GitHub のリポジトリで **Settings → Secrets and variables → Actions → Variables タブ → New repository variable**
   - Name：`SHEET_CSV_URL`
   - Value：コピーしたURL

### ④ Actions の書き込みを許可
**Settings → Actions → General → Workflow permissions** を
**「Read and write permissions」** にして Save。

### ⑤ 初回の生成
**Actions タブ → 「記事ページを生成」 → Run workflow**。
緑のチェックになれば完了です。数分後にサイトへ反映されます。

### ⑥ Google に知らせる
Google Search Console で `https://leben-k.github.io/tokinoho/sitemap.xml` を送信します。

---

## 2. ふだんの使い方

**スプレッドシートに行を追加するだけ**です。
3時間ごとに自動で生成・公開されます。すぐ反映したいときは、Actions タブから Run workflow を押してください。

- 記事を直す → スプレッドシートを直す
- 記事を消す → その行を消す（記事ページも自動で消えます）
- 本文の `【○○】` だけの行は、記事ページで小見出しになります

## 3. 安全のしくみ
- スプレッドシートが読めなかったときや、記事が0件だったときは**何も変更せずに止まります**（サイトが空になる事故を防ぎます）
- 見出しや本文に記号が入っていても、そのまま文字として表示されます

## 4. うまくいかないとき
- Actions に赤い×が出た → クリックして「スプレッドシートから生成」の行を見ると、日本語で原因が出ています
- 公開ブランチが `main` 以外（例：`master`）の場合 → `.github/workflows/build.yml` の `branches: [main]` を書き換えてください
- `index.html` を編集するときは、`<!--ARTICLES:START-->` と `<!--ARTICLES:END-->` の2行を消さないでください（この間が自動で書き換わります）
